解約・自動更新の停止

サブスクリプションは購入時に自動更新が有効となっており、次回更新日の24時間以上前に解約手続きを行わない限り、同一プランが自動的に更新されます。

解約手続きは各ストアの管理画面から行えます。

  • iOS：設定アプリ → Apple ID → サブスクリプション → 「tabilog」を選択 → 解約

解約後も、すでに支払った期間の終了日までは引き続き有料プランをご利用いただけます。
